# مركز المرفقات — واجهة الموظفين (إعادة بناء من لوفابل، TanStack Start)

واجهة أمامية فقط لصفحة الموظفين من خلفية `details-files` الحالية على 127.0.0.1:3500. كل الاستدعاءات
إلى `/api/app/*` تذهب لنفس الأصل عبر كوكي جلسة بوابة ديتيلز. لا تمسّ هذه الواجهة صفحات العملاء العامة
(`/r/:token`, `/s/:token`) ولا `/api/public/*` — تلك تبقى كما هي على الخلفية القديمة.

## البناء
```
npm install
NITRO_PRESET=node-server npm run build
node .output/server/index.mjs   # PORT/HOST عبر env
```

## النشر
راجع `deploy/install.sh` — يبني التطبيق، يثبّت `details-filehub-ui.service` على المنفذ 3501، ويستبدل
nginx tunnel على سيرفر التطبيقات بإعداد يقسّم المسارات: `/r`, `/s`, `/public`, `/api/*`, `/internal`
تبقى على الخلفية القديمة (3500) دون أي تغيير، وشاشة الموظفين (`/`, `/app/*`) تذهب للواجهة الجديدة
(3501). نسخة احتياطية تلقائية من الإعداد القديم في `*.tunnel.bak` للتراجع الفوري عند الحاجة.
